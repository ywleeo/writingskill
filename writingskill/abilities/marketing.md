# 能力：营销文案

写出有**心智、有干货、能出圈**的营销内容。把"一个无名的东西"，靠**一个卖点 / 一句广告词 / 一个心智**打成"大家都知道"。含一句话卖点、slogan、广告词、段子、帖子、口播短视频、剧情短视频。

## 核心认知（判断标准）

> **看"从无名到知名"的真实案例，别看不评奖的作品、也别看已经知名企业的动作——那些无法效仿，也没有"从 0 到 1"的效果。**
> 营销的核心是新鲜感、新奇感、新潮感；人云亦云、司空见惯是死敌。
> 而且，**看起来像广告的广告已经死了**：用户见识多、广告疲劳，要干货、要参与感、要情绪投射，不要被当成被营销的对象。

所以判断一段营销文案好不好，标准是——**它能不能立一个"心智"、能不能出圈、有没有"量"**。不是美不美、情怀不情怀。

## 怎么做（找一个能立心智的卖点 / 一句出圈的广告词）

钩子 = **卖点 × 角度 × 声口**。

- **卖点**：只留一个，而且必须是**能立心智**的那个——用户记住一个词就够了（"0糖0脂0卡""3秒即溶"）。别堆优点。
- **角度**：新鲜 / 反常识。复用 [开脑洞](brainstorm.md)。
- **声口**：像真人说，别品牌腔。复用 [去 AI 味](de-ai-flavor.md)。
- **钩子句**：参考 [写标题](titles.md) 的留白 / 态度 / 具体。

然后问自己三个问题（决定能不能出圈）：

1. **这一个点，用户听完能记住吗？** 一句话说清，还是得听一堆？
2. **这个说法新鲜吗？** 是不是"司空见惯、人云亦云"？是，就重来。
3. **它像广告吗？** 像，就死。能不能做成用户愿意看 / 愿意转的"内容 / 素材"，而不是塞给他的广告？

## 格式路由（7 种）

| 格式 | 结构 / 字数 | 声口 | 要注意（当下标准） |
|---|---|---|---|
| 一句话卖点 | 一句，口语 | 直接 / 有梗 | 给一个具体、能立心智的点，别"好品质 / 极致" |
| slogan | 短 | 态度 / 反常识 / 梗 | 别空喊押韵，要点立场、能出圈 |
| 广告词 | 一段，有画面 | 具体场景 | 给具体价值，别"品质生活" |
| 段子 | 短，有梗 | 反转 / 自嘲 | 越像真人借势越好，玩热点梗 |
| 帖子（社交） | 一段，口语 | 像真人发的 | 越像真诚种草 / 干货越好，别像硬广 |
| 口播短视频 | 口头，快节奏 | 高能量 / 干货前置 | **前 3 秒给钩子 + 价值**，别铺垫 |
| 剧情短视频 | 有情节 | 情绪 / 反转 | 钩子 30 秒内，让用户投射自己，别自嗨宣传 |

## 真实案例锚点库（无名 → 知名 · 靠卖点/心智/一句广告词）

这些都是**真实"从 0 到 1"**、靠一个卖点/心智/一句广告词打出来的，不是知名企业做了什么。**看它立的"心智"是什么，别照抄行业。**

- **元气森林**：*"0糖0脂0卡。"*——一个创业品牌靠这个**卖点 / 心智**成为无糖饮料头部（[七年冲刺百亿](https://www.focusmedia.cn/casedetail/256)）。
- **蜜雪冰城**：*"你爱我，我爱你，蜜雪冰城甜蜜蜜。"*——靠这句**神曲 / 广告词**出圈，从区域平价店变成全国现象级（[神曲营销](https://wap.cnki.net/touch/web/Journal/Article/LZHP202408004.html)）。
- **江小白**：*"表达瓶 / 文案"*——靠"年轻人都市情绪"的**文案心智**，一个白酒创业品牌打进了年轻人的心智（[100 条"郑重声明"](https://finance.sina.com.cn/jjxw/2021-11-23/doc-iktzqtyu8999844.shtml)）。
- **三顿半**：精品速溶咖啡，靠"小罐装 / 3 秒即溶 / 随时随地好咖啡"这个**卖点心智**，从湘江之滨走向全球（[咖啡"瞪羚"](https://changsha.voc.com.cn/news/202506/29703207.html)）。

**注意**：这些是"**从无名到知名**"的样本——它们的价值在于"一个卖点/心智就把品牌打起来了"，不是让你照抄行业或模仿大品牌动作。这才是能落地、有效果的参照。

## 注意

跟其它能力配合时，**"心智 + 人话 + 干货"三样都要**——像广告就死了，自嗨也死了，没钩子没心智也是废文案。判断就一条：**这玩意儿，能不能让一个无名的东西出圈？**
