# 能力：营销文案

写出有**心智、有干货、能出圈**的营销内容。含一句话卖点、slogan、广告词、段子、帖子、口播短视频、剧情短视频。

## 核心认知（写的时候的标准）

> **营销的核心是新鲜感、新奇感、新潮感；人云亦云、司空见惯是死敌。**
> **看起来像广告的广告，已经死了**：用户见识多、广告疲劳，要干货、要参与感、要情绪投射，不要被当成被营销的对象。
> 所以判断标准是——**能不能立一个"心智"、能不能出圈、有没有"量"**，不是美不美、情怀不情怀。

## 怎么做（找一个能立心智的卖点 / 一句出圈的广告词）

钩子 = **卖点 × 角度 × 声口**。

- **卖点**：只留一个，而且是能立心智的那个（用户记住一个词就够了）。别堆优点。
- **角度**：新鲜 / 反常识。复用 [开脑洞](brainstorm.md)。
- **声口**：像真人说，别品牌腔。复用 [去 AI 味](de-ai-flavor.md)。
- **钩子句**：参考 [写标题](titles.md) 的留白 / 态度 / 具体。

写完问自己三个问题：

1. **这一个点，用户听完能记住吗？** 一句话说清，还是得听一堆？
2. **这个说法新鲜吗？** 是不是司空见惯？是，就重来。
3. **它像广告吗？** 像，就死。能不能做成用户愿意看 / 愿意转的内容，而不是塞给他的广告？

## 格式路由（7 种）

| 格式 | 结构 / 字数 | 声口 | 要注意（当下标准） |
|---|---|---|---|
| 一句话卖点 | 一句，口语 | 直接 / 有梗 | 给一个具体、能立心智的点，别"好品质 / 极致" |
| slogan | 短 | 态度 / 反常识 / 梗 | 别空喊押韵，要点立场、能出圈 |
| 广告词 | 一段，有画面 | 具体场景 | 给具体价值，别"品质生活" |
| 段子 | 短，有梗 | 反转 / 自嘲 | 越像真人借势越好，玩热点梗 |
| 帖子（社交） | 一段，口语 | 像真人发的 | 越像真诚种草 / 干货越好，别像硬广 |
| 口播短视频 | 口头，快节奏 | 高能量 / 干货前置 | **前 3 秒给钩子 + 价值**，别铺垫 |
| 剧情短视频 | 有情节 | 情绪 / 反转 | 钩子 30 秒内，让用户投射自己，别自嗨宣传 |

## 真实案例锚点库（一句话卖点 / 心智立起来的例子）

这些是**真实的**、凭一个卖点 / 心智 / 一句广告词立起来的案例，可当"一句话卖点 / 心智"的参考声口：

- **元气森林**：*“0糖0脂0卡。”*
- **蜜雪冰城**：*“你爱我，我爱你，蜜雪冰城甜蜜蜜。”*
- **江小白**：表达瓶 / 年轻人都市情绪文案。
- **三顿半**：小罐装 / 3秒即溶 / 随时随地好咖啡。

参考它们立"点"、说人话的方式，但别照抄行业、别套模板。

## 注意

跟其它能力配合时，**“心智 + 人话 + 干货”三样都要**——像广告就死了，自嗨也死了，没钩子没心智也是废文案。
