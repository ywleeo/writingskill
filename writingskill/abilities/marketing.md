# 能力：营销文案

写出有**心智、有干货、能出圈**的营销内容。含一句话卖点、slogan、广告词、段子、帖子、口播短视频、剧情短视频。

## 怎么做

**0. 先讨论，别拿起来就写。** 前面的环节不是"问几个问题填个表"，是**和用户把"真的东西"聊出来**——它藏在细节、故事、反例、甚至含糊的话里。几个做法：

- **追含糊**：用户说"好用 / 强大 / 最好"，追下去——"具体哪里好用？跟哪个比好？当时什么场景让你觉得它好？"
- **追故事**：用户提到一个转折（"我做不了行距字间距，才自己做"），顺着挖——"当时你在干嘛？用什么？卡在哪？"
- **挑战弱答案**："最好用的"这种，反问——"这个怎么证明、谁信？你真正跟别人不一样的是哪一点？"
- **回述确认**：聊到差不多，主动把理解说给用户听——"我理解你的产品是…，最不一样的点是…——对吗？"确认了再动笔。
- **别急着写**：真实定位没聊清楚前，别落笔。写歪一堆再返工，不如先聊对一句。

（真实素材：产品定位 / 官网 / 已有文案是 ground truth，顺着它放大、别另起炉灶。）

**1. 定心智，但先验证，别急着写。** 找到候选心智后，先过这四关再动笔：
- **区分度**：这心智，替代品 / 更大的产品是不是已经占了这个说法？占了，就弱。
- **一致性**：这心智，跟产品真正的定位 / 它自己说的一致吗？不一致，就换。
- **根由**：这是产品的"stance / 为什么"，还是只是某个功能？
- **懂行用户认不认**：熟悉这领域的人，会说"对，就是这样"，还是"所以呢"？

**2. 让它新鲜**：用 [开脑洞](brainstorm.md) 换非常规角度——别用司空见惯的说法。
**3. 说成人话**：用 [去 AI 味](de-ai-flavor.md) 给身份锚 + 一句真实母语，别用品牌腔、别自嗨。
**4. 敲钩子句**：参考 [写标题](titles.md) 的留白 / 态度 / 具体。

写完**逐句检查**（决定能不能出圈）：

- 用户听完，能记住这一个点吗？还是得听一堆？
- 这个说法新鲜吗？还是人云亦云？
- 它像广告吗？像，重写。用户愿意看 / 愿意转吗？
- **它跟产品真实定位一致吗？**（如果产品有官网/定位，以它为准，别为了"出圈"把产品说偏了。）

## 格式路由（7 种）

| 格式 | 结构 / 字数 | 声口 | 要注意（当下标准） |
|---|---|---|---|
| 一句话卖点 | 一句，口语 | 直接 / 有梗 | 给一个具体、能立心智的点，别"好品质 / 极致" |
| slogan | 短 | 态度 / 反常识 / 梗 | 别空喊押韵，要点立场、能出圈 |
| 广告词 | 一段，有画面 | 具体场景 | 给具体价值，别"品质生活" |
| 段子 | 短，有梗 | 反转 / 自嘲 | 越像真人借势越好，玩热点梗 |
| 帖子（社交） | 一段，口语 | 像真人发的 | 越像真诚种草 / 干货越好，别像硬广 |
| 口播短视频 | 口头，快节奏 | 高能量 / 干货前置 | **前 3 秒给钩子 + 价值**，别铺垫 |
| 剧情短视频 | 有情节 | 情绪 / 反转 | 钩子 30 秒内，让用户投射自己，别自嗨宣传 |

## 真实案例锚点库（一句话卖点 / 心智立起来的例子）

这些是**真实的**、凭一个卖点 / 心智 / 一句广告词立起来的案例，当"一句话卖点 / 心智"的声口参考：

- **元气森林**：*“0糖0脂0卡。”*
- **蜜雪冰城**：*“你爱我，我爱你，蜜雪冰城甜蜜蜜。”*
- **江小白**：表达瓶 / 年轻人都市情绪文案。
- **三顿半**：小罐装 / 3秒即溶 / 随时随地好咖啡。

学习它们立"点"、说人话的方式，别照抄行业、别套模板。

## 注意

跟其它能力配合时，**“心智 + 人话 + 干货”三样都要**——别像广告、别自嗨；没钩子没心智，就是废文案。
