# 能力：写标题

给出 3 个留白、有态度、让人想点进去的标题。

## 何时用

需要标题时，或对“这条内容让人点进来”有要求时。

## 怎么做

标题不写总结，写钩子。**先问一句：母语者会原样说吗？** 别让句子“端起”来，也别写成书面总结。三件事：

1. **留白，别说全。** 给一个“刺激”，信息藏一半，让人点进去补全。“我为什么劝你别随便辞职”比“辞职要慎重”有点击欲。
2. **有态度，别中立。** 得有倾向，替某部分人说他们想说又不敢说的话。“都是打工人，谁也别装”比“职场沟通建议”有态度。
3. **给具体，别给抽象。** 数字、人群、场景、一个真实的时代梗，比形容词有用。“28 岁裸辞，我靠这 3 件事活下来”。

## 输出

3 个标题，风格差异明显（一个悬念 / 一个反常识或梗 / 一个情绪或人群），别三个同质化。写完逐个过：**母语者会原样说出来吗？** 太文绉绉、太“金句腔”的，往人话改。

## 正例 / 反例

**反例（无感 / 书面）：**《咖啡的好处》《关于咖啡的几点思考》

**正例（真实高赞标题 · 三种风格三种平台）：**
- 反常识 / 有梗：《一人表忠心，全组判无期》（小红书 1.6 万赞）
- 设问 / 反直觉：《很多人吐槽现在下班时间晚，哪里晚了？》（B站 57 万播放）
- 疑问 / 勾子：《打工人为什么不能拒绝加班？》（知乎问题）

## 标题锚点库（真实高赞 · 三平台）

写标题前先看**真实高赞标题**找声口，别自己空想。**留白、有态度、是真人会说的话**，别写“金句腔 / 书面总结”。

**小红书（笔记标题）：**
- 《一人表忠心，全组判无期》（1.6万赞）——反常识 / 有梗
- 《一种很新的随地大小睡…》（2.2万赞）——留白 / 口语
- 《十级孤独，你能承受几级？》（979 评论）——悬念 / 互动
- 《毕业后住的巴掌大出租屋，下班后 be like》（5303 赞）——具体 / 留白
- 《24岁｜月薪四千｜房租700｜下班后的独处》——具体 / 数字

**B站（视频标题）：**
- 《我这么努力的工作，可能就是为了让老板过上更好的生活》（264 万播放）——反常识 / 自嘲
- 《上班就得当海王》（194 万播放）——有梗 / 隐喻
- 《你拒绝加班的样子很美！》（140 万播放）——态度 / 反转
- 《很多人吐槽现在下班时间晚，哪里晚了？》（57 万播放）——设问 / 反直觉

**知乎（问题标题）：**
- 《打工人为什么不能拒绝加班？》——疑问 / 勾子
- 《普通的打工人准时下班，没有加班，公司的天会塌下来吗？》——留白 / 反问
- 《为什么感觉公司打工人厌恶加班，而工厂打工人却渴望加班？》——对比 / 好奇
