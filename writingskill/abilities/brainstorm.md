# 能力：开脑洞

跳出第一反应，找一个不常用的角度。

## 何时用

内容老套、没新意，或者第一反应就是“常见的那套”的时候。用户说“要不一样 / 要爆款”时几乎必用。

## 输入

主题 + 已有素材（或一句想写的话）。

## 怎么做

别停在第一个联想——第一个联想是所有人的联想，没有价值。往外跳：

1. **随手列第一反应，然后划掉它。** 第一反应的对照物，就是这套东西想避开的“默认语义场”。
2. **跨域拉一个类比。** 把主题硬拽到无关领域：咖啡 → 烟、通勤、看病、台风、老照片。挑一个能用、且第一眼想不到的。
3. **换个视角。** 主角换配角、结果换过程、产品换用的人、“是什么”换“不是什么”。
4. **往反常识走。** 找一个跟常识反着、但站得住的说法——比说正确的废话有意思。
5. **量化或具象化。** 把抽象概念换成具体数字、场景、物件。

## 输出

3 个以上不同角度的选题 / 类比 / 说法，每个带一句“为什么这个角度成立”。先量后选，不带评价。

## 正例 / 反例

**反例（第一反应 / 默认联想）：**写咖啡，就写“咖啡带来温暖和惬意”。

**正例（开脑洞后）：** 写咖啡，从“人是靠糖和咖啡因续命的社会动物”入手，把咖啡喝成一种工种的证据。
