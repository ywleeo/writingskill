# 能力：开脑洞

跳出第一反应，找一个不常用的角度。

## 何时用

内容老套、没新意，或第一反应就是“常见那套”的时候。用户说“要不一样 / 要爆款”时几乎必用。

## 输入

主题 + 已有素材（或一句想写的话）。

## 怎么做

第一个联想是所有人的联想，没有价值。开脑洞不是“多想几个”，是**换个身份、换个场合，让这个主题长成不一样的东西**——多变、杂糅，正是人味。别停在“这个主题原本该怎么说”。

换着来，别都用一个人、一个场合：

1. **换身份看。** 换成不同的人——用它的、把它用坏的、做它的、讨厌它的、路过只瞥一眼的、凌晨还靠它续命的。每个身份都是一条不同的话。
2. **换场合看。** 把主题从“客厅 / 官网”挪到别处——凌晨便利店、急诊室、坟头、相亲桌、末班车。场合一变，话说出来就活了。
3. **跨域拽一个类比。** 硬拽到无关领域（咖啡 → 烟、通勤、看病、台风、老照片）。挑一个第一眼想不到、但贴着要写的东西长的。
4. **反着来。** 主角换配角、结果换过程、“是什么”换“不是什么”；找一个跟常识反着、但站得住的说法。
5. **攥成一个具体的。** 把抽象概念换成具体数字、场景、物件、一个真实的人。

## 输出

**给用户多个角度去挑，别只交一个创意。** 5 个以上**不同身份 / 不同场合**的角度（越多越好），每个带一句“为什么这个角度成立”——先量后选，不带评价、别急着定。别五个都“同一个人想同一件事”；要是没挤够，就再换身份、换场合往下抠。

**用数量换质量。** 脑洞 / 创意很难一次想到对的，一个创意常常连自己都说不服；给一堆候选，用户总能挑到半个对的，他挑出来的那个往往就是对的。这是给「失望」留台阶，也是给「选中」留可能。别给用户一个答案让他点头，要给他一张菜单让他挑。

## 正例 / 反例

**反例（第一反应 / 默认联想）：** 写咖啡，就写“咖啡带来温暖和惬意”。

**正例（开脑洞后 · 换身份 / 场合）：** 不从“咖啡好喝”写，从“谁还在深夜需要它”写。贴着真实场景——“大家都是如何习惯活着大部分时间都在上班呢”——把咖啡写成这届人的**续命工具**，而不是一杯暖暖的惬意。

## 角度锚点库（分析真实内容得出的切入方式）

**这里是“角度”，不是“标题”。** 角度是**从哪看这事的思路**（怎么想），标题是**把它说成什么**（怎么写）。下面的角度都是从**读完的真实内容**里分析出来的，不是看一眼标题就拿来用；每条都贴一句原文作证据。

1. **换一把尺子，重新定义问题**——不把“加班”当“钱 / 累”来谈，换成“消耗你不可挽回的时间”来量。solakulo（知乎）：*“时间，用掉了就是用掉了，你怎么都拿不回来……人是会死的。”*
2. **用一个反常框架翻转评价**——把“上班的恶”定义成“让人变懒、获得‘摆烂的特权’”，用“受害者道德高地”这个反常识角度。三吉吖523（知乎）：*“我就天然站到了‘受害者’的道德高地。”*
3. **情绪落到一个无冲突的具体场景**——写“委屈”不写吵架，落到“推开门看见老公自顾自打游戏”这一个动作。微博《已婚打工人》：*“推开家门，看见老公自顾自打游戏，屋内冷冷清清。”*
4. **自嘲 + 荒诞细节写“累”**——不说累，说“累得不能哭，因为骑车擦眼泪不安全”。B站《我这么努力……》：*“累，但是我不能哭，因为骑共享单车的时候擦眼泪不安全。”*
5. **文化挪用**——把经典（阿Q）挪进现代职场，写内卷和“底层逻辑”。微博《阿Q混进现代职场》：*“他只是混进了现代职场。”*

角度别停在“这主题本该这么说”。以上是**从内容里读出来的切入方式**——记住你拿到的是“怎么想”，不是“怎么命名它”。
