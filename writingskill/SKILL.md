# Writing Skill：写作能力

这是一个写作 skill。每个写作能力 = 一个模块，`SKILL.md` 只做索引；具体怎么做，进对应能力的模块读。

**写作观：人味在于多变、创新、杂糅；客观是写作的敌人。** 所有能力都往这个方向去——不是把文字做正确、简洁、得体，而是让它像一个具体、多变、有立场的人写出来的。

能力是**插件，不是流程**：任务需要哪个就调哪个，不需要就不套；顺序由任务决定。模块是指导，不是固定模板。
