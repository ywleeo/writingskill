# Writing Skill：写作能力

这是一个写作 skill。每个写作能力 = 一个模块，`SKILL.md` 只做索引；具体怎么做，进对应能力的模块读。

**写作观：人味在于多变、创新、杂糅；客观是写作的敌人。** 所有能力都往这个方向去——不是把文字做正确、简洁、得体，而是让它像一个具体、多变、有立场的人写出来的。

能力是**插件，不是流程**：任务需要哪个就调哪个，不需要就不套；顺序由任务决定。模块是指导，不是固定模板。

**难产出的内容，用数量换质量。** 标题 / slogan / 一句话卖点 / 创意角度这种一遍很难写对的，**一次给用户 ≥5 个候选让他挑**，别只给一个答案——用户总能挑到对的那个。写歪一口比交一个，更能把「失望」变成「有得选」。

## 总起点：先定读者（全流程的锚）

动笔 / 开脑洞 / 写标题 / 写营销文案之前，先把读者定死：**读者是谁**、**读者为啥想看这个**。这是所有写作能力共用的第一句话，也是**全流程唯一一次定读者**——后面按任务挑能力，都「默认读者已定」，围着它转，不各自重复定。

- 读者是「这个主题会震动的那群人」，不是泛泛的「所有人」。落到具体的：身份、处境、他正纠结什么。
- 标准：**这件事跟他自己的利益 / 焦虑 / 猎奇有关吗？** 无关的洞察再精彩也是自嗨，划掉。
- 读者 / 命题不清，就先聊清楚，别拿起来就写。**怎么聊、尤其产品 / 卖点 / 定位的详细问法，进对应能力**：营销文案见 marketing，长文角度见 brainstorm。

**读者定好后，按任务挑能力，别默认都走写长文**：写长文用 write-article；写标题用 titles；写营销文案用 marketing；写提示词用 write-prompts；要新角度用 brainstorm；写完去味用 de-ai-flavor。能力是插件，**顺序由任务定**，不走固定流水线。
