# Writing Skill：给 AI 写提示词

提示词不是越长越好。大神写的提示词短、信号密、每一句都用到。**先给模型身份，再给任务，再给一条好例子，够了就停。**

一段提示词只需回答：你是谁、要做什么、素材在哪、别做什么、做成什么样。五句能说清就不用六句。

## 标准长这样

```
你是一个资深广告文案。把下面这套咖啡卖点改写成三条小红书文案：
1) 不许出现“丝滑醇厚”这类词；2) 每条 30 字内；3) 每个都带一个生活场景让人想喝。
卖点：……[素材放这]
```

## 写好它的四条

1. **少即是好。** 删掉客套、解释、形容词。模型越强，越不需要你替它铺路。
2. **把任务说成动作。**“写一篇”不如“以【角度】写出【几点】”，能指定结果就不留余地。
3. **给“好”的样子。** 一句话说明或一条示例，比任何形容词都让 AI 对齐。
4. **只写必要的约束。** 真正要避开的才写“不要……”，废话一条都别放。

## 写的时候

- 素材不全：一句话反问，或给个明确假设让用户确认，别脑补。
- 写完自问：删掉哪句还能看懂？剩下每句是不是都有用？

**这是指导，不是固定模板**——该短就短，用户要的细节才补。
